# Installation

In order to run the application, do the following commands:

1. `npm i` to install dependencies
2. `npm start` to run the app

# App evaluation

The `Booking page` for project evaluation can be accessed from the home page using the `Reserve a table` button.

Relevant components are included in the `pages` folder of this project:

- `BookingPage` this page contains the table booking content
- `BookingForm` this component handles form and inputs
- `ConfirmedBooking` this page displays the confirmation after making a table reservation
